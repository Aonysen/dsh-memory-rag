# dsh-memory-rag 1.1.3

New artwork, plus the safety work from the 1.1.x line.

## Icon

- Side-view brain drawn from the reference artwork: head outline and brainstem removed, transparent background, no tile.
- One uniform 2 px stroke with round caps and joins; 64×64 canvas so the glyph stays crisp at any size.
- Updated storefront tile: `docs/icon-180.png`.

## Since 1.0.0

- **1.1.0 — concurrent writes and boundaries**
  - Every write re-stats and reloads the index before mutating it, and compaction reloads too: one process can no longer erase records another just wrote.
  - Lock wait is capped (`lockWaitMs`, default 100 ms) and surfaces as `StoreBusyError`; tools retry asynchronously for ~2.5 s instead of blocking the event loop.
  - `rag_ingest` gained `ingestDeny` / `ingestRoots` / `ingestOutsideCwd` guards and warns when reading outside the working directory.
  - API keys prefer the DSH credentials service; on Windows the key file gets a best-effort `icacls` restriction.
  - `largeStoreWarning` plus a measured scale table in the README (1k / 5k / 20k entries).
- **1.1.1 — plugin detail page**
  - `meta.detail` points at short intro documents (`docs/intro.zh.md`, `docs/intro.en.md`) instead of falling back to the full README.
- **1.1.2 — new icon**
  - Monochrome brain mark replacing the old blue gradient tile.
- **1.1.3 — icon refinement**
  - Uniform, rounded strokes on a larger canvas.

## Install

```bash
dsh plugin add dsh-memory-rag
```

Or from GitHub: `dsh plugin add github:Aonysen/dsh-memory-rag`.

Existing memories and the API key are untouched; the data directory is unchanged.
