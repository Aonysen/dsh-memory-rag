# dsh-memory-rag

给 DeepSeek Harness 用的**本地 RAG 记忆**：记忆存在本机向量库里，用的时候再检索，不再把整份笔记常驻塞进系统提示词。

- **五个工具**：`rag_search`（检索）、`rag_remember`（写入一条事实）、`rag_ingest`（导入 md/mdx/txt 文件或目录）、`rag_forget`（删除）、`rag_stats`（状态）。
- **三种运行模式**：云端 OpenAI 兼容 embeddings（千问 / 硅基流动 / OpenAI / 自定义）、本地 Ollama、完全离线的 BM25 关键词模式（不需要 Key、不需要联网、不需要下载模型）。
- **会话索引注入**：会话开始时注入一小段本地渲染的索引（置顶 + 当前项目近期 + 文件聚合），零网络请求、不随轮次变化。
- **设置页**：切换提供商、填 API Key（只写不读）、选模型与维度、调检索参数、测试连接、浏览记忆库。
- **侧栏「记忆洞察」**：KPI、每日新增、构成、标签、存储占用与 56 天活跃度。

装好后打开 **设置 → RAG 记忆**：想零配置就直接选「本地关键词（BM25）」；想语义检索就选提供商并粘贴 Key。重启一次 DSH 桌面端并刷新页面即可生效。

数据都在本机 `<DSH_HOME>/memories/dsh-rag-memory/`，只有你显式写入或导入的文本会发往你配置的嵌入端点。
